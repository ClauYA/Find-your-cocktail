# Find Your Cocktail

A web application that helps you discover cocktail recipes by name. Search for any cocktail and get instant access to its image and preparation instructions.

## About

Find Your Cocktail is a simple yet elegant cocktail search application that connects to a cocktail database API. 
Whether you're a bartender looking for inspiration or someone who wants to learn how to make classic drinks, this app provides quick access to cocktail recipes.

## Features

- **Search Functionality**: Find cocktails by name
- **Visual Results**: Display cocktail images
- **Detailed Instructions**: Step-by-step preparation guide
- **Clean Interface**: User-friendly design with responsive layout
- **Real-time Data**: Fetches live data from cocktail API

## Technologies

- HTML5
- CSS3
- JavaScript
- TheCocktailDB API
